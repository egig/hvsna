## Creating a Task

1. Tap the **+** button
2. Enter a task name — you can type a tag inline with `#`, e.g.
   `Read Quran #daily` (see [Tags](/help/tags))
3. Optionally add a description
4. Optionally set a **date**, and either a **clock time** or a **prayer**
   (Fajr, Sunrise, Dhuhr, Asr, Maghrib, Isha) for that day
5. Optionally add tags or a repeat rule
6. Tap **Save**

A task with no date lands in your **Inbox** until you schedule it.

## What a Task Can Hold

- **Title**
- **Description**
- **Date** with an optional **time** *or* an optional **prayer association** —
  prayer-anchored tasks sort into their prayer slot for that day
- **Tags**
- **Repeat** rule — see [Recurring Tasks](/help/recurring-tasks)

## Where Tasks Appear

- **Today** — everything scheduled for today, grouped by time and prayer, with a
  **Completed** group at the bottom
- **Upcoming** — the days ahead
- **Inbox** — tasks with no date yet
- **Recurring** — your repeat templates
- **Completed** — finished tasks
- **Search** — find any task by text
- Open a tag to see just the tasks carrying it

## Completing a Task

Tap the checkbox. The task shows as done for a moment, then moves into the
**Completed** group. Tap the checkbox again to bring it back.

## Editing a Task

Tap the task to open it, change any field, and save.

## Deleting a Task

1. Open the task
2. Open the menu (⋯) and choose **Delete**

Deleted tasks can't be recovered. For a recurring task you'll be asked whether
to delete one occurrence or all of them.
