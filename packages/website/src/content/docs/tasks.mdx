## Creating a Task

Add a new task in seconds:

1. Tap the **+** button on the home screen
2. Enter task name (e.g., "Read 2 pages of Quran")
3. (Optional) Add description or tags
4. Set due date/time or link to prayer time
5. Tap **Save**

## Task Details

Each task can include:

- **Title**: Brief description of what to do
- **Description**: Additional details, links, or context
- **Due Date/Time**: When the task should be completed OR **Prayer Association**: Link to a specific prayer time
- **Tags**: Categories for organization
- **Recurring**: Repeat daily, weekly, monthly, yearly, or custom schedule

## Managing Your Tasks

### Marking Complete

Tap the checkbox next to a task to mark it done. Completed tasks:

- Move to the "Completed" section
- Can be viewed for the day

### Editing Tasks

Tap any task to edit:

- Update title, description
- Change due dates or prayer associations
- Add or remove tags
- Adjust recurrence settings

### Deleting Tasks

1. Open the task
2. Tap the menu (⋯)
3. Select **Delete**

Deleted tasks cannot be recovered.


## Quick Actions

Speed up task management with gestures:

- **Swipe Right**: Quick complete
- **Swipe Left**: schedule
