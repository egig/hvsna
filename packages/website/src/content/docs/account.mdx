## Account Overview

Your Hvsna account centralizes:

- Login credentials (email/password)
- Synced data across devices
- Subscription status (if applicable)
- Security settings
- Data export and deletion options

## Account Settings

### Profile Information

Update your basic info:

1. Go to **Settings → Account → Profile**
2. Edit:
   - Display name (shown in shared tasks)
   - Profile picture (optional)
   - Time zone (auto-detected or manual)
3. Tap **Save**

### Email Address

Change your login email:

1. Go to **Settings → Account → Email**
2. Enter new email address
3. Verify with current password
4. Check new email for verification link
5. Click link to confirm change

**Note:** You must verify the new email before it becomes active.

### Password

Change your password:

1. Go to **Settings → Account → Password**
2. Enter current password
3. Enter new password (8+ characters recommended)
4. Confirm new password
5. Tap **Update**

**Password Tips:**
- Use a mix of letters, numbers, symbols
- Don't reuse passwords from other sites
- Consider using a password manager

## Security Settings

### Two-Factor Authentication (2FA)

Add an extra layer of security:

1. Go to **Settings → Account → Security → 2FA**
2. Tap **Enable**
3. Scan QR code with authenticator app (Google Authenticator, Authy, etc.)
4. Enter the 6-digit code from app
5. Save backup codes securely

**Using 2FA:**
- Enter email and password normally
- Then enter code from authenticator app
- Or use a backup code if phone unavailable

### Active Sessions

View and manage where you're signed in:

1. Go to **Settings → Account → Security → Active Sessions**
2. See:
   - Device name and type
   - Location (approximate)
   - Last active time
3. Sign out any suspicious sessions
4. Sign out all devices if needed

### Sign Out Everywhere

Secure your account by signing out all devices:

1. Go to **Settings → Account → Security**
2. Tap **Sign Out All Devices**
3. Re-authenticate on devices you still use

## Subscription Management

### Free vs. Premium

**Free Plan:**
- Unlimited tasks
- Basic prayer times
- Local storage
- Single device

**Premium Plan:**
- Cross-device sync
- Advanced notifications
- Widgets
- Priority support
- Export/import features

### Managing Subscription

**View Status:**
1. Go to **Settings → Account → Subscription**
2. See current plan and renewal date

**Upgrade:**
1. Tap **Upgrade to Premium**
2. Select billing option (monthly/annual)
3. Complete payment
4. Features activate immediately

**Cancel:**
1. Go to **Settings → Account → Subscription**
2. Tap **Cancel Subscription**
3. Follow cancellation steps
4. Premium features remain until period ends

**Restore Purchase:**
If you reinstall Hvsna:
1. Sign in with same account
2. Go to **Settings → Account → Subscription → Restore**
3. Previous purchases reactivate

## Data Management

### Export Your Data

Download a copy of everything:

1. Go to **Settings → Data → Export Data**
2. Choose format:
   - **JSON**: Complete data (tasks, settings, history)
   - **CSV**: Tasks only (spreadsheet compatible)
3. Tap **Export**
4. Save file to secure location

### Delete Account

Permanently remove your account and all data:

1. Go to **Settings → Account → Delete Account**
2. Read warnings carefully
3. Enter password to confirm
4. Type "DELETE" to finalize
5. Tap **Permanently Delete**

**What gets deleted:**
- ✅ All tasks and history
- ✅ Account information
- ✅ Synced data from all devices
- ✅ Subscription records

**What remains:**
- Local app data on devices (until app uninstalled)
- Analytics data (anonymized, no PII)

## Account Recovery

### Forgot Password

Reset via email:

1. On sign-in screen, tap **Forgot Password**
2. Enter your email
3. Check email for reset link
4. Click link and create new password
5. Sign in with new password

### Lost Access to Email

If you can't access your email:

1. Contact support@hvsna.com
2. Provide proof of account ownership:
   - Approximate account creation date
   - Devices used
   - Recent task content
3. Support will verify and help recover

## Privacy Settings

### Data Collection

Control what data is collected:

1. Go to **Settings → Privacy**
2. Toggle:
   - Analytics (usage statistics)
   - Crash reports
   - Marketing emails (if any)

### Third-Party Access

Review connected services:

1. Go to **Settings → Privacy → Connected Apps**
2. See any integrations
3. Revoke access if needed

## Account Tips

**Best Practices:**
- Enable 2FA for security
- Use a strong, unique password
- Regularly review active sessions
- Export data backups periodically
- Keep recovery email up-to-date
