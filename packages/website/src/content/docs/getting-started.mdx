## Get the App

Install Hvsna from
[Google Play](https://play.google.com/store/apps/details?id=com.hvsna.app).

No account or sign-up is needed to start.

## Set Up (About a Minute)

### 1. Location

On first launch Hvsna asks for location permission so it can calculate prayer
times. Allow it, or pick your city from the search box if you'd rather not.
See [Setting Your Location](/help/location).

### 2. Create a Task

1. Tap the **+** button
2. Type a task name (e.g. "Read Quran")
3. Optionally pick a date and a prayer or time for it
4. Tap **Save**

### 3. Check Your Settings (Optional)

Confirm the prayer **calculation method** and **madhab** match what your local
authority uses, and set your language. See [Settings](/help/general-settings).
