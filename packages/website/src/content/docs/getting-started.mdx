## Quick Setup (3 Minutes)

### 1. Set Your Location

Hvsna needs your location to calculate accurate prayer times:

- **Auto-detect**: Tap "Allow Location" when prompted, if not allowed you will be asked to search  and choose a location.


### 2. Create Your First Task

1. Tap the **+** button on the home screen
2. Enter a task name (e.g., "Read Quran")
3. Choose date and choose a prayer time if desired (e.g., "Fajr")
4. Tap **Save**
