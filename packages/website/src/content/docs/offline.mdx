## Working Offline

Hvsna is designed to work fully offline. Whether you're in airplane mode, traveling, or in an area with poor connectivity, all features remain available.

## What Works Offline

### Fully Functional Offline

**Tasks:**
- ✅ Create new tasks
- ✅ Edit existing tasks
- ✅ Mark tasks complete
- ✅ Delete tasks
- ✅ View all task history

**Prayer Times:**
- ✅ View today's prayer times
- ✅ Calculate times for your saved location


## What Requires Internet

### Online-Only Features

These features need a connection:

- 🌐 Initial prayer time calculation for new locations
- 🌐 Cross-device sync
- 🌐 Account sign-in/sign-up
- 🌐 App updates
- 🌐 Contacting support
- 🌐 Data export to cloud storage

## Offline Prayer Times

### Pre-calculation

Prayer times for your location are pre-calculated:

- Today's times: Always available offline
- This month: Calculated and stored
- Full year: Stored for your set location

### New Locations Offline

If you need prayer times for a new location while offline:

- Use the last saved location
- Or manually enter coordinates (if known)
- Times update once you're back online

## Sync Queue

### Pending Changes

When you make changes offline, they're queued:

1. Create or edit a task while offline
2. A "pending sync" indicator appears
3. Changes are saved locally immediately
4. Once online, automatic sync occurs


## Preparing for Offline Use

### Before Going Offline

If you know you'll be offline:

1. **Sync Everything**: Pull down to refresh and ensure latest data
2. **Check Location**: Verify prayer times show for correct location
3. **Test**: Put phone in airplane mode briefly to confirm functionality


## Back Online

### Reconnecting

When you regain internet:

1. All changes sync automatically
2. Check **Settings → Sync** to confirm
3. Green checkmark = all caught up
4. Review any conflict notifications


## Limitations

### Be Aware

When offline, you cannot:

- Calculate prayer times for brand new locations
- Sync with other devices

Plan accordingly for extended offline periods.
