## Working Offline

Hvsna stores everything on your device, so it keeps working with no connection.

## What Works Offline

- Create, edit, complete, and delete tasks
- View all of your task history
- View prayer times for your saved location — today, and any date, since they're
  computed on the device
- Change settings

## What Needs a Connection

- Detecting or searching for a **new** location (prayer times for a location you
  haven't used before)
- Cross-device sync
- Signing in, signing up, and email verification
- Subscription checkout and management

## Sync While Offline

If you use Sync, changes you make offline are saved locally right away and sent
up once you're back online. See [Syncing Across Devices](/help/sync).

## Keeping Your Own Backup

<PlatformTabs>
<Web>

The web app has no file export. To keep your data safe, use Sync (a cloud copy)
or a browser that you won't clear site data for.

</Web>
<Android>

**Settings → Backup & Restore → Export data** saves everything to a file you can
store yourself. **Import data** restores it later. This works fully offline.

</Android>
</PlatformTabs>

## Erasing Data From a Device

<PlatformTabs>
<Web>

**Settings → Reset Device Data** erases all Hvsna data in this browser — tasks,
settings, and location.

</Web>
<Android>

**Settings → Backup & Restore → Import data → Replace** swaps in a backup and
clears what was there. To wipe the app entirely, clear its storage in Android
system settings.

</Android>
</PlatformTabs>

This doesn't touch your account or, if you use Sync, the server copy — signing
back in re-downloads your data. It can't be undone.
