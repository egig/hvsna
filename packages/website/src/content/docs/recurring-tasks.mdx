description: Set up tasks that repeat automatically.

## Creating a Recurring Task

1. Create a new task or open an existing one
2. Tap the **date** field, then **Repeat**
3. Choose how often it repeats:
   - **Daily**
   - **Weekly**
   - **Monthly**
   - **Yearly**
4. Optionally set an **interval** — e.g. every **2** weeks, every **3** days
5. Optionally set when it ends (see below)
6. Save

Recurrence uses the civil (Gregorian) calendar. "Monthly" repeats on the same
day-of-month; "Yearly" repeats on the same month and day.

## Ending a Recurrence

When setting **Repeat**, choose an end condition:

- **Never** — repeats indefinitely
- **On a date** — stops after the chosen date
- **After a number of occurrences** — stops once that many have been generated

## Managing Recurring Tasks

All your recurring task templates are listed under **Recurring** in the app.

### Change the Pattern

1. Open the recurring task
2. Tap the **date** field, then **Repeat**
3. Adjust the frequency, interval, or end condition
4. Save

Changes apply to future occurrences. Occurrences you've already completed stay
in your history.

### Stop Repeating

1. Open the task
2. Tap the **date** field, then **Repeat**
3. Choose **Does Not Repeat**
4. Save

### Delete

1. Open the recurring task
2. Open the menu (⋯) and choose **Delete**
3. You'll be asked whether to delete **just this occurrence** or **all
   occurrences**
4. Confirm

Deleting all occurrences removes the template and its upcoming instances;
completed instances remain in history.
