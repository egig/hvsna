## Creating Recurring Tasks

Set tasks to repeat automatically so you don't have to recreate them:

1. Create a new task or edit an existing one
2. Tap *Date* and tap **Repeat**
3. Select recurrence pattern
4. Set end date (optional)
5. Save

Note that recurrence pattern for monthly and yearly is based on the Hijri calendar.
For example, if you set a task to repeat monthly on the 15th, it will repeat on the 15th of each Hijri month.


### Custom Patterns

For more flexibility:

- Every 3 days
- Every 2 weeks on Monday and Thursday

## Managing Recurring Tasks

### Edit Recurrence

Change a task's repeat pattern:

1. Open the recurring task
2. Tap *Date* and tap **Repeat**
3. Modify pattern or frequency
4. Save changes

**Note**: Changes apply to future instances only, not past completed tasks.


### Stop Recurring

End a recurring task:

1. Open the task
2. Tap **Repeat**
3. Select **Does Not Repeat**
4. Save

Existing completed instances remain in history.

### Delete Future Instances
