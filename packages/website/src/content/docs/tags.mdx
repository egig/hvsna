## What Are Tags?

Tags are labels that help you categorize and filter tasks. They're flexible, customizable, and make managing many tasks much easier.

## Creating Tags

Create a new tag when editing a task:

1. Open any task
2. Tap the **Tags** field
3. Select existing tags or type a new tag name
4. Tap **Done**


## Managing Tags

### Edit a Tag

Change a tag's name:

1. Go to **Settings → Tags**
2. Tap the tag you want to edit
3. Modify name
4. Tap **Save**

Changes apply to all tasks using that tag.

### Delete a Tag

Remove a tag from your system:

1. Go to **Settings → Tags**
2. Swipe left on the tag
3. Tap **Delete**
4. Confirm removal

**Note**: Deleting a tag removes it from all tasks but doesn't delete the tasks themselves.
