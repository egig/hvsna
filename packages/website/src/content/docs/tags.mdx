## What Are Tags?

Tags are labels for grouping and filtering tasks. Each tag is automatically
given a color from a small palette when it's first created.

## Adding Tags to a Task

Two ways, while creating or editing a task:

- **Inline in the title** — type `#` followed by the tag name, e.g.
  `Groceries #errands`. The tag is created if it doesn't exist yet.
- **Tags field** — open it and pick existing tags or type a new name.

## Viewing Tasks by Tag

Open a tag (from the tag list in the app's navigation) to see every task and
recurring task carrying it, active and completed.

## Renaming or Recoloring a Tag

1. Open the tag
2. Open the menu (⋯) and choose **Edit**
3. Change the name and/or pick a different color
4. Save

The change applies everywhere that tag is used.

## Deleting a Tag

1. Open the tag
2. Open the menu (⋯) and choose **Delete**, then confirm

The tag is removed from every task; the tasks themselves are not deleted.
