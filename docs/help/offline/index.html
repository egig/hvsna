Working Offline

Hvsna stores everything on your device, so it keeps working with no connection.

What Works Offline

  • Create, edit, complete, and delete tasks
  • View all of your task history
  • View prayer times for your saved location — today, and any date, since they're computed on the device
  • Change settings

What Needs a Connection

  • Detecting or searching for a new location (prayer times for a location you haven't used before)

Keeping Your Own Backup

Settings → Backup & Restore → Export data saves everything to a file you can store yourself. Import data restores it later. This works fully offline.

Erasing Data From a Device

Settings → Backup & Restore → Import data → Replace swaps in a backup and clears what was there. To wipe the app entirely, clear its storage in Android system settings.

This can't be undone.
